# Align Node support and minimum-version evidence

## Task

Set the supported Node floor to `>=22.13.0`, synchronize metadata and README, and add a CI lane that proves the minimum release.

## Why

The declared `>=22.0.0` range includes releases unsupported by the locked ESLint and Vite versions, while current CI proves only Node 24.

## Scope

**IN:** engine metadata, lock metadata, README requirement, minimum-Node CI with clean install and relevant gates.

**OUT:** dependency upgrades, formatter pinning (T7), browser build ordering (T8), dropping Node 22, or runtime behavior changes.

## Files in scope

- **Read:** locked ESLint/Vite engine metadata and existing CI jobs — verify the compatibility floor and current evidence.
- **Modify:** `package.json`, `package-lock.json`, `README.md`, `.github/workflows/ci.yml` — align contract and add the minimum lane.
- **Create:** none.

## Acceptance criteria

- Manifest and root lock metadata declare `node >=22.13.0`.
- README states the same minimum without implying Node 24 is mandatory.
- CI keeps the current Node 24 Linux/macOS/Windows matrix.
- A separate Node 22.13.x lane runs `npm ci`, lint, typecheck, tests, and build.
- The lane does not duplicate browser installation or weaken existing jobs.
