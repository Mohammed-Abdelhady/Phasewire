# Pin the formatter exactly

## Task

Change the Prettier development dependency from a semver range to exact version `3.9.6` and preserve lock integrity.

## Why

Formatting output can change across releases; an exact declaration keeps local and CI formatting reproducible.

## Scope

**IN:** root dependency declaration and corresponding lock metadata.

**OUT:** formatting source files, making formatting blocking, upgrading Prettier, configuration changes, or other dependency changes.

## Files in scope

- **Read:** `.prettierrc.json` and the current Prettier lock entry — confirm no configuration/version change is needed.
- **Modify:** `package.json`, `package-lock.json` — exact declaration and synchronized lock metadata.
- **Create:** none.

## Acceptance criteria

- `package.json` declares exactly `"prettier": "3.9.6"`.
- Root lock metadata and the installed-package lock node resolve exactly 3.9.6.
- No unrelated dependency or integrity entry changes.
- Existing `format` and `format:check` scripts remain unchanged.

## Gotchas

Do not use `npm update`; it can rewrite unrelated lock entries. The semantic diff is the manifest range plus matching root lock metadata only.

## Security constraints
