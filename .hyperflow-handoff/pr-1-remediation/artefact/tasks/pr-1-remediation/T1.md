# Make adapter path assertions cross-platform

## Task

Replace POSIX-only expected path suffixes with native path construction in adapter installation tests.

## Why

Production returns native paths, so hard-coded `/` separators fail on Windows while passing on Unix hosts.

## Scope

**IN:** test expectations for Claude flat/plugin/commands, Codex, Grok, and Agy destinations.

**OUT:** production path construction, destination layout, path normalization in durable Phasewire state.

## Files in scope

- **Read:** `packages/cli/src/adapters/hosts.ts`, `packages/cli/src/adapters/install.ts`.
- **Modify:** `packages/cli/src/adapters/install.test.ts`.
- **Create:** none.

## Acceptance criteria

- Expected suffixes use `node:path.join` or one explicit native-path helper.
- All current host/destination assertions remain present.
- Production native-path behavior is unchanged.
- No path assertion depends on the runner's separator.

| 3 | Other host paths | Install Codex, Grok, and Agy project adapters | Skills/workflows/manifests match native suffixes | Host coverage |
